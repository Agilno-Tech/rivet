# Testing Rivet

To run Rivet's development checks, follow [contributing](./contributing.md). To test it in your own project, start with a small task from the [quickstart](./getting-started.md), review the diff and inspect the recorded check results.

Automated fixtures check workflow behavior. They do not prove that every model, account, integration or desktop environment works. See [compatibility](./compatibility.md) for the tested scope.

Maintainers can use the [evaluation guide](https://github.com/FraneAgilno/rivet/blob/main/docs/maintainers/evaluations.md) for deterministic and opt-in live model tests, or the [onboarding study](https://github.com/FraneAgilno/rivet/blob/main/docs/maintainers/first-task-trial.md) to record an independent user's experience.
