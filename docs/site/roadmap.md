# What's next

Current work focuses on simpler onboarding, real-world integration testing and versioned package installation.

Future capabilities include shared project memory and automatic Bitbucket merging. They are not available today, and no release date is promised.

For what you can use now, see [capabilities and limitations](./status.md). To suggest an improvement or report a problem, [open an issue](https://github.com/FraneAgilno/rivet/issues).
